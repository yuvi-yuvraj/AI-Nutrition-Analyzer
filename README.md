# 🥗 Daily Nutrition Analyzer

An AI-powered nutrition analysis platform that helps users monitor their daily food intake, analyze nutritional values, and receive personalized AI-driven recommendations for maintaining a healthy and balanced diet.

---

## 🚀 Features

- 🍽️ Log daily food intake
- 🔥 Calculate total calories consumed
- 💪 Track protein, carbohydrates, and fat intake
- 📊 Monitor daily macronutrient distribution
- 🎯 Estimate remaining daily protein requirements
- ⭐ Generate an overall Nutrition Score
- 🤖 AI-powered nutrition analysis using Google Gemini
- 📝 Personalized dietary recommendations
- ⚡ Fast and responsive user interface

## ⚙️ How It Works

1. Enter your personal details.
2. Set your fitness or dietary goal.
3. Add all foods consumed throughout the day.
4. The application calculates:
   - Calories
   - Protein
   - Carbohydrates
   - Fat
5. Google Gemini analyzes the nutritional balance.
6. Receive personalized health recommendations and an overall nutrition score.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/Daily-Nutrition-Analyzer.git

# Navigate to project
cd Daily-Nutrition-Analyzer

# Install dependencies
npm install

# Start development server
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file in the project root and add your Gemini API key.

```env
VITE_GEMINI_API_KEY=YOUR_API_KEY
```
